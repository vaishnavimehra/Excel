🍕 Pizza Sales Analysis & Interactive Dashboard

1. Project Title / Headline

Pizza Sales Analysis & Interactive Dashboard using Excel and MySQL

2. Short Description / Project Overview

Developed an interactive Pizza Sales Analysis Dashboard to analyze sales performance, customer ordering patterns, product demand, and revenue trends. The project involved transforming raw pizza sales data into meaningful business insights using Excel and MySQL.

The dashboard provides a clear overview of key performance indicators such as Total Revenue, Total Orders, Total Pizzas Sold, and Average Order Value. It also enables users to analyze sales across different pizza categories, pizza sizes, days, and hours, helping identify top-performing products and customer ordering trends.

The project demonstrates how data analysis and visualization can be used to convert raw transactional data into actionable insights that can support business and sales decisions.

3. Tech Stack

- Microsoft Excel – Data cleaning, analysis, PivotTables, PivotCharts, slicers, and dashboard creation
- MySQL – Data querying and exploratory analysis
- SQL – Aggregations, filtering, grouping, sorting, joins, and date/time-based analysis

4. Data Source

Pizza Sales Dataset containing transactional information such as:

- Order ID
- Order Date
- Order Time
- Pizza Name
- Pizza Category
- Pizza Size
- Quantity
- Unit Price
- Total Price

The raw dataset was cleaned and analyzed to identify sales trends and business performance metrics.

5. Features / Highlights

📊 Key Performance Indicators

The dashboard presents important business KPIs in an easy-to-understand format, including:

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value

These KPIs provide a quick overview of the overall sales performance.

📅 Daily & Monthly Sales Analysis

Analyzed sales patterns across different dates and months to identify changes in customer demand and understand overall sales trends.

⏰ Hourly Order Analysis

Analyzed the number of orders placed at different hours of the day to identify peak ordering periods and understand customer purchasing behavior.

🍕 Pizza Category Analysis

Compared different pizza categories to determine which categories generated the highest number of orders and contributed most to overall sales.

📏 Pizza Size Analysis

Analyzed sales based on pizza size to identify customer preferences and determine which sizes were most frequently purchased.

🏆 Top & Bottom Performing Pizzas

Identified the best-performing and lowest-performing pizzas based on sales and order quantity, helping highlight products with strong or weak demand.

🎛️ Interactive Dashboard

Created an interactive Excel dashboard using PivotTables, PivotCharts, Slicers, and filters, allowing users to explore the data dynamically and view specific sales segments.

🗄️ SQL-Based Data Analysis

Used MySQL to perform analytical queries and extract business insights using:

- "SELECT"
- "WHERE"
- "GROUP BY"
- "ORDER BY"
- Aggregate functions such as "SUM()", "COUNT()", and "AVG()"
- "DISTINCT"
- Date and time functions
- Joins

💡 Business Insights

The analysis helps identify:

- High-performing pizza categories
- Most popular pizza sizes
- Peak ordering hours
- Top-selling products
- Revenue and order trends
- Products requiring further business attention

6. Project Outcome

This project strengthened my practical understanding of data cleaning, SQL querying, Excel-based data analysis, dashboard development, and business intelligence. It demonstrates my ability to work with raw transactional data, identify meaningful patterns, and present insights through an interactive and visually understandable dashboard.
